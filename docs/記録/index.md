# 会話記録の保存ルール（Compacting前 — 必須）

Compacting conversation が発生する前に、それまでのやり取りの要約を本ディレクトリに保存する。

## ファイル名

`[YYYYMMDD]-[topic].md`

- `[topic]` はその会話内容を端的に表す日本語の題名（例: `20260226-管理画面リード一覧のバグ修正.md`）

## 記載内容

- **目的**: その会話で達成しようとしたこと
- **実施内容**: 実際に行った変更・調査の要約
- **変更ファイル**: 変更したファイルのリスト
- **残課題**: 未完了の作業や次に必要なアクション
- **決定事項**: 会話中に決まった設計判断やルール
