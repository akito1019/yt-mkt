# 情報アーキテクチャ (IA)

## 1. サイト全体構造

```
YouTube市場調査システム (yt-mkt)
│
├── 認証エリア
│   └── ログイン (Google OAuth)
│
└── アプリケーションエリア (認証後)
    ├── ダッシュボード (ホーム)
    ├── チャンネル管理
    ├── 市場分析
    ├── ニッチ発見
    └── 設定
```

## 2. グローバルナビゲーション

### 主要ナビゲーション (左サイドバー)

```yaml

  - ホーム (ダッシュボード)

    - チャンネル一覧

アイコン:
  - ホーム: 📊 BarChart

  - 市場分析: 🎯 Target
```

### ユーティリティナビゲーション (ヘッダー右上)

```yaml
要素:

  - アカウントメニュー

```

## 3. ページ階層とURL設計

### URL構造 (RESTful設計)

```yaml
認証:
  /auth/signin: ログインページ
  /auth/callback: OAuth コールバック

ダッシュボード:
  /: ホームダッシュボード

チャンネル管理:
  /channels: チャンネル一覧
  /channels/add: チャンネル追加 (検索・保存)
  /channels/[id]: チャンネル詳細 (分析結果)
  /channels/[id]/history: 成長推移グラフ

市場分析:
  /markets: ジャンル一覧
  /markets/[genre]: ジャンル詳細分析
  /markets/difficulty: 参入難易度ランキング
  /markets/trends: 市場トレンド (時系列)

ニッチ発見:
  /niches/keywords: キーワードギャップ分析
  /niches/channels: 急成長チャンネル発見
  /niches/topics: 未開拓トピック一覧

設定:
  /settings: 設定トップ
  /settings/sheets: Google Sheets連携
  /settings/api: API設定・クォータ管理
```

### パンくずリスト設計

```yaml
ホーム:
  - ホーム

チャンネル詳細:
  - ホーム > チャンネル > [チャンネル名]

市場分析:
  - ホーム > 市場分析 > [ジャンル名]

ニッチ発見:
  - ホーム > ニッチ発見 > キーワードギャップ
```

## 4. コンテンツ階層

### ページ優先度マトリクス

| 優先度 | ページ | 理由 | アクセス頻度 |
|--------|--------|------|------------|
| P0 (最高) | ダッシュボード | 全体像把握の起点 | 毎日 |
| P0 | チャンネル一覧 | 主要機能 (検索・保存) | 毎日 |
| P0 | チャンネル詳細 | 分析の核心 | 毎日 |
| P1 (高) | 市場分析 (ジャンル一覧) | 意思決定の根拠 | 週数回 |
| P1 | ニッチ発見 (キーワード) | 機会発見 | 週数回 |
| P2 (中) | 参入難易度ランキング | 補助情報 | 週1回 |
| P2 | 急成長チャンネル | 補助情報 | 週1回 |
| P3 (低) | 設定 | 初回のみ | 初回 + 稀に |

### 情報のグルーピング原則

```yaml
ダッシュボード:
  - サマリー指標 (KPI)
  - 最近追加したチャンネル
  - 注目の市場トレンド
  - アクションアイテム (次にやるべきこと)

チャンネル関連:
  - 基本情報 (登録者数、再生数)
  - 成長指標 (30日成長率)
  - パフォーマンス (動画あたり平均再生数)
  - 投稿パターン (頻度、曜日)

市場分析関連:
  - 市場規模 (総再生数、チャンネル数)
  - 成長性 (成長率、トレンド)
  - 競合状況 (競合密度、上位独占度)
  - 参入難易度 (総合スコア)

ニッチ発見関連:
  - 機会指標 (ギャップスコア)
  - 検証データ (検索ボリューム vs 供給)
  - 推奨アクション (具体的な戦略提案)
```

## 5. ラベリング戦略

### ユーザーの言葉で命名

```yaml
避けるべき専門用語:
  NG: Metadata → OK: チャンネル情報
  NG: Query → OK: 検索
  NG: Cache → OK: データ更新
  NG: API Quota → OK: 残り取得回数

ユーザー目線のラベル:
  - "登録者数" (subscriber_count)
  - "動画あたり再生数" (avg_views_per_video)
  - "成長率" (growth_rate)
  - "参入しやすさ" (entry_difficulty_score の逆転)
  - "伸びている市場" (high_growth_markets)
  - "ライバルが少ない" (low_competition)
```

## 7. ナビゲーションパターン

### 主要な導線設計

```yaml
新規ユーザーの初回フロー:
  1. ログイン
  2. ダッシュボード (空状態)
  3. "チャンネルを追加" CTA
  4. チャンネル検索・保存
  5. ダッシュボードに戻る (データ反映)
  6. 市場分析を促すヒント表示

日常的な利用フロー:
  1. ダッシュボード (最新情報確認)
  2. 気になるチャンネル詳細へ
  3. 同ジャンル市場分析へ移動
  4. ニッチ発見で機会探索
  5. 新規チャンネル追加

意思決定フロー:
  1. 市場分析 (ジャンル比較)
  2. 参入難易度確認
  3. ニッチ発見 (具体的機会)
  4. 競合チャンネル調査 (詳細分析)
  5. 意思決定
```

### コンテキスト保持

```yaml
パンくずリスト:
  - 全ページに表示
  - クリック可能な階層リンク

戻る操作:
  - ブラウザバック対応
  - フィルタ・ソート状態を保持
  - スクロール位置を復元

関連ページへの導線:
  - チャンネル詳細 → 同ジャンル市場分析
  - 市場分析 → 該当ジャンルのチャンネル一覧
  - ニッチ発見 → 関連チャンネル詳細
```

## 9. 空状態とエラー状態

### 空状態の設計

```yaml
チャンネル一覧 (未追加):
  イラスト: 📺 空のチャンネルリスト
  メッセージ: "まだチャンネルを追加していません"
  CTA: "最初のチャンネルを追加する"

市場分析 (データ不足):
  メッセージ: "データを蓄積中です。24時間後に結果が表示されます"
  代替表示: サンプルデータのプレビュー

ニッチ発見 (該当なし):
  メッセージ: "現在、おすすめのニッチはありません"
  CTA: "検索条件を変更する"
```

### エラー状態の設計

```yaml
API制限エラー:
  メッセージ: "本日の取得回数上限に達しました"
  情報: "残り回数: 0 / 10,000"
  アクション: "明日リセットされます (あと X 時間)"

認証エラー:
  メッセージ: "Google認証の有効期限が切れました"
  アクション: "再ログイン"

データ取得失敗:
  メッセージ: "データを取得できませんでした"
  アクション: "再試行" ボタン
```

## 10. アクセシビリティを考慮したIA

### キーボードナビゲーション

```yaml
フォーカス順序:
  1. スキップリンク ("メインコンテンツへ")
  2. グローバルナビゲーション
  3. メインコンテンツ
  4. サイドバー (補助情報)

ショートカットキー (将来実装):
  - "/" : グローバル検索にフォーカス
  - "h" : ホームに戻る
  - "c" : チャンネル一覧へ
  - "m" : 市場分析へ
  - "n" : ニッチ発見へ
```

### スクリーンリーダー対応

```yaml
ランドマーク:
  - <header>: ヘッダー
  - <nav>: グローバルナビゲーション
  - <main>: メインコンテンツ
  - <aside>: サイドバー
  - <footer>: フッター

ARIA属性:
  - aria-label: ナビゲーション項目
  - aria-current="page": 現在のページ
  - aria-expanded: 折りたたみ要素
  - aria-live="polite": データ更新通知
```

## 11. まとめ

### IA設計の核心

```yaml
目的:
  - YouTubeで稼ぐための意思決定を支援
  - データに基づく市場選択を可能にする
  - 機会発見を効率化

設計原則:
  - シンプルな階層 (最大3階層)
  - ユーザーの言葉でラベリング
  - コンテキストを保持した導線
  - アクセシビリティ基準 WCAG 2.1 AA 準拠
  - モバイル対応 (レスポンシブ)

成功指標:
  - 3クリック以内で主要機能にアクセス可能
  - 初回訪問から最初のチャンネル追加まで 5分以内
  - 市場分析レポート閲覧まで 3クリック
```
