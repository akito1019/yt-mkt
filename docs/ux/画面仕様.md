- ログイン画面

1. KPIサマリーカード (3つ横並び)

   - "市場分析を見る"
   - "ニッチを発見"

- 初回ログイン時: "ようこそ! まずはチャンネルを追加しましょう"
- イラスト + "チャンネルを追加" ボタン (大きく)

### 3. チャンネル一覧

**URL**: `/channels`

**目的**: 保存したチャンネルの一覧表示と管理

**レイアウト概要**:
```
┌─────┬──────────────────────────────────────────┐
│ナビ │ ホーム > チャンネル                       │
│     ├──────────────────────────────────────────┤
│     │ チャンネル一覧              [+ 追加]     │
│     │                                          │
│     │ フィルタ: [ジャンル▼] [登録者数▼] [成長率▼]│
│     │ ソート: [成長率 降順▼]                   │
│     │                                          │
│     │ ┌──────────────────────────────────┐   │
│     │ │ [🖼️] チャンネルA                  │   │
│     │ │      ジャンル: 副業                │   │
│     │ │      登録者: 10万  成長率: +15%   │   │
│     │ │      平均再生: 5,000回             │   │
│     │ │      [詳細を見る]                  │   │
│     │ └──────────────────────────────────┘   │
│     │                                          │
│     │ ┌──────────────────────────────────┐   │
│     │ │ [🖼️] チャンネルB                  │   │
│     │ │      ...                           │   │
│     │ └──────────────────────────────────┘   │
│     │                                          │
│     │ [1] [2] [3] ... 次へ >                  │
└─────┴──────────────────────────────────────────┘
```

**主要要素**:
- ページヘッダー
  - タイトル "チャンネル一覧"
  - "チャンネルを追加" ボタン (右上)

- フィルタバー
  - ジャンル (プルダウン)
  - 登録者数範囲 (プルダウン: 1万未満/1万~10万/10万~100万/100万以上)
  - 成長率範囲 (プルダウン: 0~10%/10~30%/30%以上)

- ソート (プルダウン)
  - 成長率 (降順/昇順)
  - 登録者数 (降順/昇順)
  - 追加日 (新しい順/古い順)

- チャンネルカード (リスト表示)
  - サムネイル画像
  - チャンネル名 (クリック可能)
  - ジャンルタグ
  - 主要指標 (登録者数、成長率、平均再生数)
  - "詳細を見る" ボタン

- ページネーション (20件/ページ)

**インタラクション**:
- カードホバー: 影が濃くなる
- "詳細を見る" → チャンネル詳細へ遷移
- チャンネル名クリック → チャンネル詳細へ遷移
- フィルタ/ソート変更 → リアルタイム反映

**空状態**:
- "まだチャンネルを追加していません"
- イラスト + "最初のチャンネルを追加" ボタン

### 4. チャンネル追加 (検索)

**URL**: `/channels/add`

**目的**: YouTubeチャンネルを検索して保存

**レイアウト概要**:
```
┌─────┬──────────────────────────────────────────┐
│ナビ │ ホーム > チャンネル > 追加                │
│     ├──────────────────────────────────────────┤
│     │ チャンネルを追加                          │
│     │                                          │
│     │ チャンネル名またはURLを入力               │
│     │ ┌──────────────────────────┐           │
│     │ │ 検索: [副業サラリーマン___] │           │
│     │ └──────────────────────────┘           │
│     │ 例: "ヒカキン", "https://youtube.com/..." │
│     │                                          │
│     │              [検索する]                  │
│     │                                          │
│     │ ─────── 検索結果後 ───────              │
│     │                                          │
│     │ 検索結果 (3件)                           │
│     │ ┌──────────────────────────────────┐   │
│     │ │ [🖼️] 副業サラリーマンTV            │   │
│     │ │      登録者: 10万                  │   │
│     │ │      総再生数: 500万               │   │
│     │ │      動画数: 200本                 │   │
│     │ │      [選択して追加]                │   │
│     │ └──────────────────────────────────┘   │
│     │                                          │
│     │ ─────── 選択後 (モーダル) ───────       │
│     │                                          │
│     │     チャンネル情報の確認                 │
│     │     ┌─────────────────────┐           │
│     │     │ チャンネル: 副業...  │           │
│     │     │ ジャンル: [副業 ▼]  │           │
│     │     │ メモ: [任意______]   │           │
│     │     │                      │           │
│     │     │ [キャンセル] [保存] │           │
│     │     └─────────────────────┘           │
└─────┴──────────────────────────────────────────┘
```

**ステップ**:
1. **検索入力**
   - 大きな検索ボックス (中央配置)
   - プレースホルダー: "チャンネル名またはURLを入力"
   - 使用例を表示
   - オートコンプリート (入力中にサジェスト)

2. **検索結果**
   - カード形式 (縦並び)
   - 各カードに "選択して追加" ボタン
   - 該当なしの場合: "チャンネルが見つかりませんでした"

3. **確認モーダル**
   - チャンネル情報プレビュー
     - 名前
     - サムネイル
     - 登録者数、総再生数、動画数
     - 最近の動画3件 (サムネイル)
   - ジャンル選択 (必須)
     - プルダウン (既存ジャンル)
     - "新しいジャンルを作成" オプション
   - メモ (任意)
     - テキストエリア (100文字まで)
   - アクション
     - "キャンセル" (モーダルを閉じる)
     - "保存" (Google Sheets に保存)

4. **保存後**
   - トースト通知: "チャンネルを追加しました"
   - 選択肢表示
     - "続けて追加" → 検索画面に戻る
     - "チャンネル詳細を見る" → /channels/[id]
     - "一覧に戻る" → /channels

**状態**:
- 検索中: ローディングスピナー
- 保存中: "保存しています..." (モーダル内)
- エラー: エラーメッセージ + 再試行ボタン

│     │                                              │

│     │ │ 成長率 (90日): +40%              │      │
│     │ │ エンゲージメント率: 5.2%          │      │
│     │ └──────────────────────────────────┘      │

**主要セクション**:
1. **ヘッダー**
   - チャンネル名 + サムネイル
   - ジャンルタグ
   - アクションボタン (編集、削除)

2. **基本指標カード** (4つ横並び)
   - 登録者数 (現在値 + 増減)
   - 総再生数 (現在値 + 増減)
   - 動画数 (現在値)
   - 投稿頻度 (週あたり)

3. **成長推移グラフ**
   - 折れ線グラフ (登録者数・再生数)
   - 期間選択タブ (1ヶ月/3ヶ月/6ヶ月/1年)
   - ホバーで詳細データ表示

4. **パフォーマンス分析**
   - 動画あたり平均再生数
   - 成長率 (30日、90日)
   - エンゲージメント率 (いいね+コメント/再生数)

5. **人気動画トップ5**
   - サムネイル + タイトル
   - 再生数、公開日
   - クリックでYouTubeへ (新規タブ)

6. **投稿パターン分析**
   - 投稿頻度 (週あたり平均)
   - 人気投稿曜日
   - 動画の平均長さ

7. **関連アクション** (ページ下部)
   - "このジャンルの市場分析を見る" → /markets/[genre]
   - "類似チャンネルを探す" → /channels?genre=[genre]

**状態**:
- データ更新中: スケルトンスクリーン
- データ取得失敗: エラーメッセージ + "再試行"
- データ不足 (追加直後): "データを蓄積中です (24時間後に表示)"

### 6. 市場分析 (ジャンル一覧)

**URL**: `/markets`

**目的**: 全ジャンルの市場規模・成長性・参入難易度を比較

**レイアウト概要**:
```
┌─────┬──────────────────────────────────────────────┐
│ナビ │ ホーム > 市場分析                             │
│     ├──────────────────────────────────────────────┤
│     │ 市場分析 (ジャンル一覧)                       │
│     │                                              │
│サイド│ フィルタ:                                     │
│バー │ ┌─────────────────┐                        │
│     │ │市場規模         │                        │
│フィル│ │□ 小 □ 中 □ 大 │                        │
│タ   │ │成長率           │                        │
│     │ │[__0%_|__100%__]│ ← スライダー            │
│     │ │参入難易度       │                        │
│     │ │□★ □★★ □★★★│                        │
│     │ │                 │                        │
│     │ │[フィルタをクリア]│                        │
│     │ └─────────────────┘                        │
│     │                                              │
│     │ テーブル表示 (ソート可能)                     │
│     │ ┌─┬────┬────┬────┬────┬────┐         │
│     │ │ │ジャンル│規模│CH数│成長│難易度│         │
│     │ ├─┼────┼────┼────┼────┼────┤         │
│     │ │1│副業   │大  │150 │+50%│★★  │← クリック可│
│     │ │2│筋トレ │中  │80  │+30%│★★★ │         │
│     │ │3│料理   │大  │300 │+10%│★★★★│         │
│     │ └─┴────┴────┴────┴────┴────┘         │
│     │                                              │
│     │ 📊 グラフ表示 (切替可能)                      │
│     │ ┌──────────────────────────────────┐      │
│     │ │       成長率 vs 参入難易度 散布図  │      │
│     │ │   高成長                           │      │
│     │ │    ↑                              │      │
│     │ │    │   ●副業 (おすすめ!)        │      │
│     │ │    │      ●筋トレ               │      │
│     │ │    │            ●料理           │      │
│     │ │    └──────────→ 高難易度       │      │
│     │ └──────────────────────────────────┘      │
└─────┴──────────────────────────────────────────────┘
```

**主要要素**:
1. **サイドバーフィルタ** (左側、固定)
   - 市場規模 (チェックボックス: 小/中/大)
   - 成長率 (スライダー: 0% ~ 200%)
   - 参入難易度 (チェックボックス: ★1 ~ ★5)
   - "フィルタをクリア" ボタン

2. **表示切替** (タブ)
   - "テーブル表示" (デフォルト)
   - "グラフ表示"

3. **テーブル表示**
   - 列:
     - 順位 (自動採番)
     - ジャンル名 (クリック可能)
     - 市場規模 (小/中/大 + 総再生数)
     - チャンネル数
     - 成長率 (6ヶ月、% + 矢印)
     - 参入難易度 (★1~★5)
   - ソート: 各列ヘッダーをクリック (昇順/降順)
   - デフォルトソート: 成長率降順

4. **グラフ表示** (散布図)
   - X軸: 参入難易度
   - Y軸: 成長率
   - 各点がジャンルを表す
   - ホバーで詳細表示
   - クリックでジャンル詳細へ
   - 推奨ゾーン (高成長 & 低難易度) を色付け

**インタラクション**:
- ジャンル名クリック → ジャンル詳細へ遷移
- フィルタ変更 → リアルタイム反映
- ソート → アニメーション付き並び替え
- グラフの点ホバー → ツールチップ表示

**空状態**:
- "まだデータがありません"
- "チャンネルを追加してジャンルデータを蓄積してください"

┌─────┬──────────────────────────────────────────────┐
│ナビ │ ホーム > 市場分析 > [ジャンル名]              │
│     ├──────────────────────────────────────────────┤
│     │ ジャンル詳細分析: 副業                        │
│     │                                              │
│     │ 1. サマリーカード (4つ横並び)                 │
│     │ ┌───────┬───────┬───────┬───────┐        │
│     │ │市場規模│成長率  │競合密度│参入難易度│        │
│     │ │大      │+50%   │低     │★★     │        │
│     │ │500M再生│(6ヶ月) │150CH  │(推奨!)  │        │
