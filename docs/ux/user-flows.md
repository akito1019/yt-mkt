# ユーザーフロー設計

## 概要

YouTube市場調査システムの主要なユーザーフローを設計します。
ユーザー: YouTubeで稼ぎたいエンジニア (データドリブン、効率重視)

## フロー1: チャンネル検索・保存フロー

### 目的
競合チャンネルや参考チャンネルを検索し、分析対象として保存する

### 主要ステップ

```
[開始] ダッシュボード
  ↓
[アクション] "チャンネルを追加" ボタンをクリック
  ↓
[画面遷移] /channels/add
  ↓
[入力] 検索ボックスにチャンネル名 or URL を入力
  ↓
[処理] YouTube Data API で検索
  ├─ [成功] → 検索結果表示 (リスト形式)
  └─ [失敗] → エラーメッセージ + 再試行
  ↓
[表示] 検索結果カード表示
  - チャンネル名
  - サムネイル
  - 登録者数
  - 総再生数
  - ジャンル (自動推定 or 手動選択)
  ↓
[アクション] 目的のチャンネルを選択
  ↓
[確認] チャンネル情報のプレビュー
  - 基本情報
  - 最近の動画 (3件)
  - "このチャンネルを追加しますか?"
  ↓
[分岐] ユーザーの判断
  ├─ [はい] → 次へ
  └─ [いいえ] → 検索結果に戻る
  ↓
[入力] ジャンル選択 (プルダウン)
  - 既存ジャンル一覧
  - "新しいジャンルを作成" オプション
  ↓
[入力] メモ (任意)
  - 例: "参考にしたいチャンネル", "直接の競合"
  ↓
[アクション] "保存" ボタンをクリック
  ↓
[処理] Google Sheets に保存
  ├─ [成功] → 成功メッセージ表示
  └─ [失敗] → エラーメッセージ + リトライオプション
  ↓
[フィードバック] トースト通知
  - "チャンネルを追加しました"
  - "ダッシュボードで確認できます"
  ↓
[選択肢] 次のアクション
  ├─ "続けて追加" → 検索画面に戻る
  ├─ "チャンネル詳細を見る" → /channels/[id]
  └─ "ダッシュボードに戻る" → /
  ↓
[終了] 選択した画面へ遷移
```

### エッジケース

```yaml
既に追加済みのチャンネル:
  検出: 保存時に youtube_id で重複チェック
  対応: "既に追加されています。チャンネル詳細を表示しますか?"
  アクション: [詳細を見る] [キャンセル]

API制限エラー:
  検出: YouTube API クォータ超過
  対応: "本日の取得上限に達しました (残り: 0/10,000)"
  代替: "チャンネルURLから直接追加" オプション表示

チャンネルが見つからない:
  検出: 検索結果が0件
  対応: "チャンネルが見つかりませんでした"
  提案: "チャンネルURLで直接追加してみてください"

Google Sheets 保存失敗:
  検出: Sheets API エラー
  対応: ローカルストレージに一時保存
  通知: "オフラインで保存されました。次回同期時に反映されます"
```

### 認知負荷の最小化

```yaml
デフォルト値:
  - ジャンル: 前回選択したジャンル
  - メモ: 空 (任意項目)

自動補完:
  - チャンネル名入力時にサジェスト表示
  - 過去に検索したチャンネルを優先

進捗表示:
  - ステップインジケーター (1. 検索 → 2. 選択 → 3. 保存)
  - ローディング時はスピナー + メッセージ

離脱防止:
  - 入力途中の離脱時に確認ダイアログ
  - "保存せずに戻りますか?"
```

## フロー2: 市場分析レポート閲覧フロー

### 目的
ジャンル別の市場規模・成長性・参入難易度を把握し、参入判断を行う

### 主要ステップ

```
[開始] ダッシュボード or グローバルナビ
  ↓
[アクション] "市場分析" をクリック
  ↓
[画面遷移] /markets
  ↓
[表示] ジャンル一覧テーブル
  - ジャンル名
  - 市場規模 (総再生数)
  - チャンネル数
  - 成長率 (6ヶ月)
  - 参入難易度スコア (★★★☆☆)
  - ソート可能 (各列ヘッダー)
  - フィルタ可能 (サイドバー)
  ↓
[インタラクション] ソート・フィルタリング
  - デフォルト: 成長率降順
  - フィルタ: 市場規模、成長率、難易度
  ↓
[アクション] 気になるジャンルをクリック
  ↓
[画面遷移] /markets/[genre]
  ↓
[表示] ジャンル詳細分析レポート
  ┌────────────────────┐
  │ 1. サマリーカード    │
  │   - 市場規模         │
  │   - 成長率           │
  │   - 参入難易度       │
  │   - 総合評価 (推奨度)│
  └────────────────────┘
  ┌────────────────────┐
  │ 2. トレンドグラフ    │
  │   - 過去6ヶ月の推移  │
  │   - 総再生数の変化   │
  └────────────────────┘
  ┌────────────────────┐
  │ 3. 競合状況          │
  │   - チャンネル数     │
  │   - 上位10の独占率   │
  │   - 競合密度         │
  └────────────────────┘
  ┌────────────────────┐
  │ 4. 成功パターン      │
  │   - 平均投稿頻度     │
  │   - 人気動画の傾向   │
  │   - サムネイルパターン│
  └────────────────────┘
  ┌────────────────────┐
  │ 5. 代表チャンネル    │
  │   - 上位5チャンネル  │
  │   - クリックで詳細へ │
  └────────────────────┘
  ↓
[スクロール] レポートを下まで閲覧
  ↓
[選択肢] 次のアクション (ページ下部CTA)
  ├─ "このジャンルのニッチを探す" → /niches/keywords?genre=[genre]
  ├─ "代表チャンネルを詳しく見る" → /channels?genre=[genre]
  └─ "他のジャンルと比較する" → /markets
  ↓
[終了] 選択した画面へ遷移
```

### インタラクションパターン

```yaml
ソート機能:
  - 各列ヘッダーをクリック
  - 昇順/降順の切り替え (アイコン表示)
  - 現在のソート列をハイライト

フィルタリング:
  位置: 左サイドバー
  種類:
    - 市場規模: スライダー (小/中/大)
    - 成長率: スライダー (0% ~ 200%)
    - 参入難易度: チェックボックス (★1~★5)
  適用: リアルタイム反映
  リセット: "フィルタをクリア" ボタン

グラフインタラクション:
  - ホバーで詳細データ表示
  - 期間選択 (1ヶ月/3ヶ月/6ヶ月/1年)
  - ズーム可能 (マウスドラッグ)

代表チャンネルクリック:
  - チャンネル詳細へ遷移
  - 新規タブで開く (Ctrl+Click)
  - 現在のレポートページは保持 (戻るボタンで復帰)
```

### エッジケース

```yaml
データ不足 (新規ジャンル):
  表示: "データを蓄積中です"
  代替: サンプルデータで表示 (透明度50% + 注釈)
  アクション: "チャンネルを追加してデータを増やす"

該当ジャンルなし (フィルタ後):
  表示: "条件に一致するジャンルがありません"
  提案: "フィルタを緩めてみてください"
  アクション: "フィルタをリセット" ボタン

API制限でグラフ取得失敗:
  表示: プレースホルダーグラフ + エラーメッセージ
  代替: "前回のキャッシュデータを表示しています (更新: X日前)"
  アクション: "明日再試行してください"

長時間データ取得 (重い分析):
  表示: プログレスバー + 推定残り時間
  メッセージ: "市場データを分析中... (約30秒)"
  キャンセル: "中止" ボタン表示
```

### 認知負荷の最小化

```yaml
視覚的階層:
  - サマリーカード: 最も目立つ配置
  - グラフ: 2番目に重要
  - 詳細データ: 折りたたみ可能

プログレッシブ・ディスクロージャー:
  - 初期表示: サマリー + グラフのみ
  - "詳細を見る" で追加情報展開
  - "全て展開" オプションあり

一貫性:
  - 全ジャンルで同じレポート構成
  - アイコン・色の統一
  - 指標の定義を常に参照可能 (? アイコン)

コンテキスト保持:
  - 前回見たジャンルをハイライト
  - フィルタ設定を保存 (セッション)
  - スクロール位置を復元 (ブラウザバック時)
```

## フロー3: ニッチ発見フロー

### 目的
競合が少なく需要のあるキーワード・トピックを発見し、参入機会を特定する

### 主要ステップ

```
[開始] ダッシュボード or 市場分析レポート
  ↓
[アクション] "ニッチ発見" をクリック
  ↓
[画面遷移] /niches (ランディング)
  ↓
[表示] ニッチ発見の選択肢
  ┌────────────────────┐
  │ 1. キーワードギャップ│ ← 最も推奨
  │    検索需要 vs 供給  │
  └────────────────────┘
  ┌────────────────────┐
  │ 2. 急成長チャンネル  │
  │    登録者1万未満     │
  └────────────────────┘
  ┌────────────────────┐
  │ 3. 未開拓トピック    │
  │    需要あり供給なし  │
  └────────────────────┘
  ↓
[アクション] "キーワードギャップ" を選択
  ↓
[画面遷移] /niches/keywords
  ↓
[表示] 初期状態
  - 検索ボックス (メインキーワード入力)
  - 例: "プログラミング", "料理", "筋トレ"
  - ジャンルフィルタ (任意)
  ↓
[入力] メインキーワードを入力
  例: "副業"
  ↓
[アクション] "ニッチを探す" ボタンをクリック
  ↓
[処理] キーワードギャップ分析
  1. 関連キーワード取得 (YouTube Suggest API)
  2. 各キーワードの検索ボリューム推定
  3. 既存動画数をカウント
  4. ギャップスコア計算 (需要 / 供給)
  ↓
[表示中] ローディング画面
  - プログレスバー
  - "関連キーワードを分析中... (1/3)"
  - "検索ボリュームを推定中... (2/3)"
  - "ギャップを計算中... (3/3)"
  ↓
[表示] 結果一覧 (テーブル)
  ┌─────┬────────┬────────┬────────┬────────┐
  │順位  │キーワード│検索需要 │動画数   │ギャップ │
  ├─────┼────────┼────────┼────────┼────────┤
  │1    │副業 在宅│高      │少      │★★★★★│← 推奨
  │2    │副業 初心者│中      │中      │★★★☆☆│
  │3    │副業 スマホ│中      │多      │★☆☆☆☆│
  └─────┴────────┴────────┴────────┴────────┘
  - デフォルトソート: ギャップスコア降順
  - 上位10件を表示
  ↓
[アクション] 気になるキーワードをクリック
  ↓
[展開] キーワード詳細パネル (右サイド)
  ┌────────────────────┐
  │ キーワード: "副業 在宅"│
  ├────────────────────┤
  │ ギャップスコア: ★★★★★│
  │ 検索需要: 高          │
  │ 既存動画数: 127本     │
  │ 競合レベル: 低        │
  ├────────────────────┤
  │ 推奨アクション:        │
  │ - このキーワードで動画作成│
  │ - ロングテールを狙う   │
  │ - "副業 在宅 初心者" など│
  ├────────────────────┤
  │ 関連チャンネル:        │
  │ (このキーワードで成功  │
  │  しているチャンネル3件)│
  │ [チャンネルA] 詳細→   │
  │ [チャンネルB] 詳細→   │
  ├────────────────────┤
  │ 参考動画:             │
  │ (上位動画3本のリンク) │
  └────────────────────┘
  ↓
[選択肢] 次のアクション
  ├─ "このキーワードを保存" → 保存 (Google Sheets)
  ├─ "関連チャンネルを分析" → /channels/[id]
  ├─ "別のキーワードで再検索" → 検索ボックスへ
  └─ "市場分析を見る" → /markets/[genre]
  ↓
[終了] 選択した画面へ遷移
```

```yaml

  - 入力中に推奨キーワードをプレビュー

  - ギャップスコア (★3以上のみ表示)

詳細パネル:
  - スライドイン表示 (右から)
  - 閉じる: パネル外クリック or Escキー
  - パネル内スクロール可能

保存機能:
  - "このキーワードを保存" ボタン
  - タグ付け可能 (例: "優先度高", "要検討")
  - 保存後に "保存済みニッチ一覧" へのリンク表示
```

### エッジケース

```yaml
検索結果が0件:

  理由: "全てのキーワードで競合が多いです"
  提案:
    - "もっと具体的なキーワードで検索"
    - "別のジャンルを試す"
  例: "副業 在宅 シニア向け" など

API制限エラー:
```
